# EHT-acquire
- code needed to run the EHT-scope hardware and automate acquisition from a 24-well plate
- requires Micromanager 1.4

## EHT_controller.ino
- arduino sketch to run the arduino user interface of EHT-scope

## EHT_acquire_v2.bsh
- Micromanager 1.4 beanshell script for automated acquisition

## BaslerCameraInitialize.bsh
- Micromanager 1.4 beanshell script to configure the Basler Camera
