** Code for EHT-scope **
1. **EHT-controller:** arduino code that controlls the optical pacer, focus, and white light illumination.  
2. **EHT-acquire:** BeanShell script that runs in MicroManager 1.4 to automate data acquisition.  
3. **EHT-motion:** ImageJ/Fiji plugin that converts video data to post position vs time file.  
4. **EHT-analyze:** Matlab script that reads post position vs time file and reports contraction and relaxation kinetics and force.
